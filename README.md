# Order Management System — University Thesis

This repository contains my university thesis project: **Ανάπτυξη ενός Microservices Συστήματος Διαχείρισης Παραγγελιών (Order Management System) με Spring Boot και Spring Cloud**.

The application uses a Spring Boot and Spring Cloud backend, a React frontend, and Keycloak for authentication. It supports product browsing, shopping carts, orders, inventory management, and email notifications.

- `backend/` — backend microservices.
- `frontend/` — React application.
- `my-theme/` — custom Keycloak login theme.
- `documentation/` — thesis in PDF and Word formats.
